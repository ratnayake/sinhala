සිංහල පහසුවෙන් ලියන්න

EasyAkuru මඟින් ඔබ දැනටමත් භාවිතා කරන යතුරුපුවරුවෙන්ම Windows හි ඕනෑම යෙදුමක සිංහලෙන් ටයිප් කළ හැක. වචනය උච්චාරණය වන ආකාරයට ලතින් අකුරින් ("සිංග්ලිෂ්") ටයිප් කරන්න; ඔබ ටයිප් කරන විටම EasyAkuru එය සිංහල යුනිකෝඩ් බවට පරිවර්තනය කරයි.

එය ක්‍රියා කරන්නේ මෙහෙමයි

  1. mama වගේ වචනයක් ලියන්න — ලතින් අකුරින්, උච්චාරණය අනුව.
  2. කර්සරය අසල කුඩා යෝජනා කවුළුවක සිංහල අක්ෂර වින්‍යාසය (මම) සහ ඊට ගැලපෙන අංක සහිත වෙනත් විකල්ප පෙන්වයි.
  3. Space, Enter හෝ විරාම ලකුණක් ඔබලා පළමු යෝජනාව තහවුරු කරගන්න, නැත්නම් වෙනත් වචනයක් ඕන නම් 1–9 අතර අංකයක් ඔබන්න. ටයිප් කළ ලතින් අකුරු එලෙසම තබා ගැනීමට Esc ඔබන්න.

ඔබ තෝරන විකල්ප EasyAkuru මතක තබා ගන්නා බැවින් ඊළඟ වතාවේ ඒවා මුලින්ම පෙන්වයි. උදාහරණයක් ලෙස api → අපි, kohomada → කොහොමද.

විශේෂාංග

  • ඕනෑම යෙදුමක

    Word ඇතුළු Office යෙදුම්, වෙබ් බ්‍රව්සර්, ඊමේල්, chat යෙදුම් සහ Notepad වැනි ඔබ දැනටමත් භාවිතා කරන යෙදුම් සමඟ එය ක්‍රියා කරයි. යතුරුපුවරු පිරිසැලසුම මාරු කිරීමට හෝ භාෂා පැකේජයක් ස්ථාපනය කිරීමට අවශ්‍ය නැත.

  • යෝජනා කවුළුව

    ඔබ ටයිප් කරන විට කර්සරය අසල පෙනෙන කුඩා කවුළුවක සිංහල අක්ෂර වින්‍යාසය සහ අංක සහිත විකල්ප පෙන්වයි. ඔබ තෝරාගත් විකල්ප මතක තබාගෙන ඊළඟ වතාවේ ඒවා මුලින්ම පෙන්වයි.

  • Ctrl+Space එකෙන් මාරු වෙන්න

    සාමාන්‍ය ඉංග්‍රීසියෙන් ටයිප් කිරීමට අවශ්‍ය විටෙක Ctrl+Space ඔබන්න, නැත්නම් tray මෙනුව භාවිතා කරන්න. නැවත සිංහලට මාරු වීමට එය ආයෙත් ඔබන්න.

  • පුරනය වන විට ආරම්භ වේ

    EasyAkuru පළමු වරට විවෘත කළ පසු, ඔබ Windows වෙත පුරනය වන සෑම විටම එය ස්වයංක්‍රීයව ආරම්භ වේ. මෙය ඕනෑම වේලාවක Windows Settings > Apps > Startup හි අක්‍රිය කළ හැක.

  • පෞද්ගලික සහ ලෝකල්

    සියලු සැකසීම් ඔබගේ පරිගණකය තුළම, මතකයේ පමණක් සිදු වේ. EasyAkuru හි කිසිදු ජාල විශේෂාංගයක් නැත — ඔබගේ යතුරු එබීම් කිසි විටෙකත් යවන්නේ, ගබඩා කරන්නේ හෝ ලොග් කරන්නේ නැත. දැන්වීම්, ගිණුම් හෝ analytics නැත. මුරපද ක්ෂේත්‍ර හඳුනාගෙන ඒවා මඟ හැරීමට EasyAkuru උත්සාහ කරයි (හොඳම උත්සාහයක් ලෙස).

තිර රූප

නිතර අසන ප්‍රශ්න

මගේ මුරපද ක්ෂේත්‍ර ආරක්ෂිතද?

ඔව්. EasyAkuru සම්මත Windows මුරපද කොටු හඳුනාගෙන ඒවා මඟ හැරීමට උත්සාහ කරයි, නමුත් සමහර විශේෂයෙන් සාදන ලද ඒවා හඳුනා නොගැනීමට ඉඩ ඇත.

මගේ දත්ත ජාලයට යවනවාද?

නැත. EasyAkuru හට ජාල ප්‍රවේශයක් නැත; සියල්ල ඔබගේ පරිගණකය තුළම, මතකයේ පමණක් සිදු වේ.

එය සියලුම යෙදුම් සමඟ ක්‍රියා කරනවාද?

එය සම්මත Windows යතුරු ආදානය භාවිතා කරන බොහෝ යෙදුම් සමඟ ක්‍රියා කරයි. සමහර විශේෂ යෙදුම් සමඟ වෙනස්කම් තිබිය හැක.

1. ඔබ ටයිප් කරන දේ

ඕනෑම යෙදුමක ඉංග්‍රීසි අකුරින් ටයිප් කරන වචන සිංහලට හැරවීමට (උදා: mama → මම), EasyAkuru ට ඔබ ඔබන යතුරු දැකිය යුතුයි. මේ සඳහා එය Windows හි සම්මත පද්ධති-පුරා යතුරුපුවරු hook එකක් භාවිත කරයි.

  • ඔබ දැනට ටයිප් කරන වචනයේ ඉංග්‍රීසි අකුරු රඳවා තබා ගන්නේ ඔබේ පරිගණකයේ මතකයේ (memory) පමණයි; වචනය අවසන් වූ විගස ඒවා මකා දමයි.
  • ඔබ ඔබන යතුරු කිසිවිටෙක ගොනුවකට ලියන්නේවත්, සටහන් (log) කරන්නේවත්, අන්තර්ජාලය හරහා යවන්නේවත් නැත.
  • Ctrl+Space මඟින් EasyAkuru නවතා තැබූ විට, එය යතුරු නොසලකා හරියි.

2. මුරපද කොටු

ඔබ ටයිප් කරන්නේ Windows හි සම්මත මුරපද කොටුවක නම්, EasyAkuru එය හඳුනාගෙන කිසිවක් නොකර යතුරු ඒ ආකාරයෙන්ම ඉදිරියට යවයි. නමුත් මෙය හැකි උපරිමයෙන් කරන්නකි: සමහර යෙදුම් හා වෙබ් අඩවි තමන්ගේම ආකාරයේ මුරපද කොටු භාවිත කරන අතර EasyAkuru ට ඒවා හඳුනා නොගත හැකිය. එවිටත් යතුරු සුරකින්නේවත් යවන්නේවත් නැත; යෝජනා කොටුව පෙන්වීමට පමණක් ඉඩ ඇත. කැමති නම්, මුරපදයක් ටයිප් කිරීමට පෙර Ctrl+Space ඔබා EasyAkuru නවතා තබන්න.

3. ඔබේ පරිගණකයේ සුරකින ගොනු

EasyAkuru සුරකින්නේ ගොනු දෙකක් පමණයි. ඒවා ඔබේ Windows පරිශීලක පැතිකඩේ ඇති අතර කිසිවිටෙක අපට හෝ වෙන කිසිවෙකුට යවන්නේ නැත.

  • %AppData%\EasyAkuru\settings.json — සැකසුම් දෙකක්: EasyAkuru ක්‍රියාත්මකද යන්න සහ Windows වෙත පුරනය වන විට ආරම්භ විය යුතුද යන්න.
  • %AppData%\EasyAkuru\user-dictionary.json — යෝජනා කොටුවෙන් අංකයක් ඔබා ඔබ තෝරාගත් වචන: ඔබ ටයිප් කළ ඉංග්‍රීසි අක්ෂර වින්‍යාසය (උදා: mama) සහ ඔබ තෝරාගත් සිංහල වචනය. මුරපද කොටුවක ටයිප් කළ දෙයින් කිසිවක් මෙහි සුරකින්නේ නැත.

ඔබ කලින් "SinhalaInput" නම් පැරණි අනුවාදය භාවිත කළේ නම්, යාවත්කාලීන කිරීමේදී EasyAkuru මෙම ගොනු %AppData%\SinhalaInput සිට එක් වරක් පිටපත් කරයි. පැරණි පිටපත් ඔබ මකන තුරු එහිම පවතී.

4. අන්තර්ජාලය, දැන්වීම් සහ විශ්ලේෂණ

EasyAkuru හි අන්තර්ජාල සම්බන්ධතා කේත කිසිවක් නැත. එය භාවිත සංඛ්‍යාලේඛන, telemetry හෝ බිඳවැටීම් වාර්තා එකතු කරන්නේ නැත. දැන්වීම්, ගිණුම්, හෝ වෙනත් සමාගම්වල විශ්ලේෂණ මෙවලම් ද නැත.

5. ඔබේ දත්ත පාලනය කරන්නේ කෙසේද

  • තෝරාගත් වචන මකන්න: tray මෙනුවෙන් Exit තෝරා, user-dictionary.json මකන්න.
  • සියල්ල මකන්න: EasyAkuru වසා %AppData%\EasyAkuru ෆෝල්ඩරය (සහ ඇත්නම් %AppData%\SinhalaInput) මකන්න.
  • පුරනය වන විට ආරම්භ වීම නවත්වන්න: Windows Settings > Apps > Startup හෝ Task Manager හි Startup apps පිටුවෙන් EasyAkuru අක්‍රිය කරන්න.
  • අස්ථාපනය කරන්න: Windows Settings > Apps > Installed apps හි EasyAkuru තෝරා Uninstall ඔබන්න. Microsoft Store ස්ථාපනයකදී Windows සාමාන්‍යයෙන් යෙදුමේ ගොනු ද ඉවත් කරයි; සහතික වීමට ඉහත ෆෝල්ඩර ද මකන්න.

මෙම වෙබ් අඩවිය cookies, විශ්ලේෂණ මෙවලම් හෝ scripts භාවිත නොකරයි. එය Cloudflare Pages මත සත්කාරකත්වය (hosting) ලබයි. පිටු ලබා දීමට සහ අඩවිය ආරක්ෂා කිරීමට, Cloudflare ඔබේ IP ලිපිනය, බ්‍රවුසර තොරතුරු සහ ඉල්ලූ පිටුව වැනි සම්මත තාක්ෂණික තොරතුරු සකසයි (Cloudflare Privacy Policy).

Support

Everything you need to install, set up, and troubleshoot EasyAkuru, the Sinhala phonetic (Singlish) typing tool for Windows 10/11.

Installing EasyAkuru

  1. Open the EasyAkuru listing on the Microsoft Store.
  2. Select Get / Install and let the Store install the app.
  3. Select Open (or find EasyAkuru in the Start menu) to launch it for the first time.

EasyAkuru is published by Ratcon (author: Isuru Ratnayake). Installing from the Store also keeps EasyAkuru updated automatically.

First run and the tray icon

EasyAkuru runs quietly in the background — there's no main window. After launching it, look for its icon in the Windows notification area (system tray), on the taskbar. Windows sometimes hides tray icons in the "overflow" area (the small up-arrow next to the clock); if you don't see it, click that arrow, then drag the EasyAkuru icon out to keep it visible.

Right-click (or left-click, depending on your Windows version) the tray icon to open its menu:

Menu itemWhat it does
EnabledTurns transliteration on or off (same as Ctrl + Space)
SettingsOpens the settings window
AboutShows the app version and publisher
ExitCloses EasyAkuru

Turning EasyAkuru on and off

Press Ctrl + Space at any time to toggle EasyAkuru on or off without closing it — useful when you need to type plain Latin text for a moment. You can also toggle it from the tray menu's Enabled item. While it's off, every key you press is passed straight through untouched.

Starting at Windows sign-in

EasyAkuru can start automatically when you sign in to Windows. How you control this depends on how you installed it:

  • Microsoft Store install: auto-start is managed by Windows itself as a startup task, not by a setting inside EasyAkuru. Turn it off in Settings › Apps › Startup (or the Startup apps tab in Task Manager) — find EasyAkuru in the list and switch it off.
  • Direct-download build: EasyAkuru's own Settings window has a "start at sign-in" checkbox you can turn on or off directly.

Troubleshooting

The candidate popup isn't showing

  • Check that EasyAkuru is enabled (tray icon menu, or press Ctrl + Space).
  • Make sure the field you're typing into is focused and is a normal text field — the popup only appears while a word is being typed.
  • EasyAkuru deliberately does not show the popup, or transliterate at all, in fields it recognizes as password fields (see below).

It doesn't type into some windows

EasyAkuru cannot inject text into a window that is running elevated (opened with "Run as administrator") unless EasyAkuru itself is also running elevated — this is a Windows security restriction (User Interface Privilege Isolation), not a bug. Running EasyAkuru elevated all the time isn't recommended; if you occasionally need Sinhala input in an elevated window, close and reopen EasyAkuru with "Run as administrator" for that session.

Password fields

EasyAkuru tries to detect standard Windows password fields and disengages completely there so your keystrokes pass through untouched. This detection is best-effort — it may not recognize password-style fields built with fully custom controls. See the Privacy page for details.

Chrome, Edge, and other browsers

EasyAkuru works in Chromium-based browsers, but locating the exact on-screen caret position in these apps sometimes takes an extra fallback step behind the scenes, since they don't expose the caret the same way classic Windows apps do. If the candidate popup ever appears slightly out of place in a browser, the transliteration and text itself are still correct — try clicking into the field again if the popup position looks off.

Conflicts with other IMEs or the Windows Sinhala keyboard

EasyAkuru works as a global keyboard hook, not as a registered Windows input method, so it can conflict with another Sinhala input method (including Windows' own built-in Sinhala keyboard layout) if both are active at the same time and try to interpret the same keystrokes. If you notice odd or doubled-up transliteration, disable the other Sinhala input method (or switch your Windows input language back to English) while using EasyAkuru, and keep only one Sinhala typing tool active at a time.

Uninstalling

  1. Open Settings › Apps › Installed apps (or Control Panel's "Uninstall a program").
  2. Find EasyAkuru in the list and select Uninstall.

Uninstalling removes the app itself. EasyAkuru's local settings and word-preference data live in %AppData%\EasyAkuru under your Windows user profile; if you'd like to remove that too, you can delete that folder yourself after uninstalling.

Reporting a bug

Found something wrong — a word that transliterates incorrectly, a crash, or anything else? Email isuru.sampath@ratnayake.info with what you typed, what you expected, and what happened instead.

You can also open an issue on GitHub, where EasyAkuru's source code is public.

FAQ

Is EasyAkuru free?

See the current price and availability on the Microsoft Store listing.

Does it work offline?

Yes. EasyAkuru transliterates entirely on your device and makes no network connections of any kind.

Does it store what I type?

No. Only the word currently being typed is held in memory, and only until it's committed. If you pick a non-default spelling from the candidate popup, EasyAkuru remembers that already-committed word locally so it can offer it first next time — see the Privacy page for the full details.
